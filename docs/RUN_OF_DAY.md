# Run of the day

## Before: any time before Thursday 19 November

1. **Deploy** the app (see README) and open `/staff` on your phone. Check the green *Live* dot.
2. **Athletes** (Setup, 1): paste the list from the school spreadsheet. Check the house counts look right. Anyone missing? Use *Add one athlete*.
3. **Events** (Setup, 2): tick the events and age groups, press *Create events*. Set start times for field events if needed. Track and relay events do not use scheduled times or a stopwatch. Check each event's athletes (Manage). Use **Make heats** for races with many athletes (for example heats of 8).
4. **Team** (Setup, 3): one recorder account per official. Give each their password in person.
5. **Day** (Setup, 4): check the title, date, venue and the points scale (default 10, 7, 5, 3, then 1). Choose whether the public page shows full names or first name and initial.
6. **Practise:** run a pretend race on a phone with a few friends, then *Clear all results* (Day, Start again). Take a backup (Day, Download a backup).

## At the field: one recorder per event

- Sign in once; the session lasts 24 hours. Add the staff page to the phone's home screen.
- **Track races:** tap each athlete as they cross the line to save that heat's finish order. After all heats, adjust the combined event-wide order with ↑ ↓. Press **Finish event** when done; anyone left blank can be marked "did not start".
- **Heats:** use the heat tabs to record each race. Places across heats are not timed; staff adjust the combined order after all heats.
- **Jumps and throws:** tap the athlete, type the distance, press Save. The best mark counts.
- **Relays:** tap a house team once when it finishes; no leg splits are recorded.
- **Wrong name tapped?** Use ↑ ↓ in the finishing order, or Undo last.
- **No signal?** Keep tapping. Finish order is saved on the phone (a banner says how many) and sent when the connection returns.

## After

1. Check **Standings**. Fix anything with the ⋯ menu (admins can still edit after finalising).
2. **Day, Finalise the day.** Recorders are now locked out, the public page shows the champion house, and the report says FINAL.
3. Open `/report` and print or save as PDF. Download the CSV and a backup.
